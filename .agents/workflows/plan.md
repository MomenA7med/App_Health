# Flutter Planning Workflow

## Important

Do not modify files.

## Analyze the request

Identify:

- Feature requirements
- Figma requirements
- API requirements
- Navigation
- User interactions

## Inspect the project

Search for:

- Similar features
- Existing APIs
- Existing models
- Existing repositories
- Existing state management
- Existing widgets
- Existing DI
- Existing navigation
- Existing localization

## Figma

If Figma is provided:

- Use Figma MCP.
- Inspect the relevant frame.
- Analyze layout.
- Analyze spacing.
- Analyze typography.
- Analyze colors.
- Analyze components.
- Analyze assets.

## API

If API details are provided:

- Analyze endpoint.
- Analyze HTTP method.
- Analyze request.
- Analyze response.
- Identify required models.
- Identify repository changes.

Do not invent API fields.

## Output

Create a detailed implementation plan:

1. Architecture
2. UI
3. Models
4. API
5. Repository
6. State management
7. DI
8. Navigation
9. Localization
10. Tests
11. Files to create
12. Files to modify
13. Risks and edge cases

Do not implement anything.
